Pengaturan Model
Mesin Suara (TTS)

Browser = suara bawaan sistem. Gradio = perilaku lama (endpoint space). OpenAI-compatible = endpoint base, dipanggil di <endpoint>/v1/audio/speech — voice/model otomatis ditarik dari server bila mendukung. Gemini & ElevenLabs = cukup API key; daftar voice & model muncul otomatis. "Gaya bicara" = aksen/emosi/tempo (Gemini via prompt gaya, [OI] gpt-4o-mini-tts via instructions). Kecepatan bicara di atas = tempo suara remote. Kustom = POST JSON {text} → audio biner atau JSON {audio|url}.

Disimpan per-model di dalam character sheet. Pitch & kecepatan langsung terasa saat karakter bicara.
